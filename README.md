# rap_lottery
SAP ABAP RAP Example: Lottery App

A company wants to launch a marketing campaign for its customers, offering a "Lottery" where winners receive special product discounts of maximun 30%.
To maintain complete operational control over the campaign, the company required its development team to build a custom SAP Fiori application. To align with corporate IT objectives, the solution adheres strictly to Clean Core principles.
To meet these requirements, the developer implemented the project using the SAP RESTful Application Programming Model (RAP) on BTP (ABAP Cloud).
